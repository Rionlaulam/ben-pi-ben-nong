# เป็นพี่เป็นน้อง (Ben Pi Ben Nong) Website

This is a static one-page campaign website. It works with GitHub Pages and does not need a build step.

## Files

- `index.html` - page content
- `styles.css` - visual design and responsive layout
- `script.js` - mobile menu, copy-account button, and image fallback
- `images/` - add your campaign photos here

## How to Preview in VS Code

1. Open this folder in Visual Studio Code.
2. Install the “Live Server” extension if you do not already have it.
3. Right-click `index.html`.
4. Choose “Open with Live Server”.

You can also double-click `index.html` to open it directly in a browser.

## Photos

The current page uses the photos already placed in the `images` folder:

- `08.jpg` for the hero
- `02.jpg` and `06.jpg` for the camp journey
- `01.jpg`, `03.jpg`, `04.jpg`, `07.jpg`, and `05.jpg` for the activity gallery
- `QR.png` for the donation QR code

You can replace any of those files with a new image using the same filename.

## How to Publish on GitHub Pages

1. Create a new GitHub repository.
2. Upload `index.html`, `styles.css`, `script.js`, and the `images` folder to the repository.
3. Go to repository Settings.
4. Open Pages.
5. Under “Build and deployment”, choose “Deploy from a branch”.
6. Select your main branch and the root folder.
7. Save and wait for GitHub to publish the site.
